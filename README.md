# Birthday Assistant V5

A bilingual Birthday Assistant built using Python, Flask, HTML, CSS and JavaScript.

## About the Project

Birthday Assistant helps users manage birthdays, find upcoming celebrations, and generate personalized birthday wishes.

## Features

- Birthday chatbot using Natural Language Understanding (NLU).
- Dialogue state and conversation context.
- English and Kannada language support.
- Voice input with speech-to-text.
- Voice responses using text-to-speech.
- Interactive birthday calendar.
- Upcoming birthday countdown.
- Personalized birthday wish generator.
- WhatsApp and email wish sharing.
- Birthday greeting card generation.

## Technologies Used

- Python
- Flask
- Pandas
- Ollama
- HTML
- CSS
- JavaScript
